I first created a rectangle using the draw tool, which I then combined with a half circle to form the base shape of the keychain. After that, I used the extrude tool to give it depth and create a solid shape. Then, I drew another circle on the base shape using the draw tool and used the extrude tool again, but this time I selected the **remove** option to create the keychain hole.

Next, I selected the sketch option and used the text tool to write my name on the keychain. I extruded the text to give it more depth so it would pop out from the base shape. Finally, I used the Boolean tool to combine everything and create the finished keychain.

Then, I created two more circles on opposite sides of the rectangle to form the holes, and I removed these sketches using the extrude-remove option.

Next, I created a cylinder that would hold the wheels to the base object. After that, I designed a cap piece that allows the entire structure to stay together. When we combine four caps, two wheels, two pipes and two base shapes, we successfully create a two-wheeled, motorcycle-like object.

After sketching another circle, I extruded it with a greater depth to create a pipe on the base shape. Then I created another pipe on top of that pipe to form the star‑like circumference. After making one hole through the pipe, I used the circular pattern tool so the hole would appear on all sides.

Once one pipe was covered with smaller pipe holes, I used the circular pattern tool again to copy the pipes around in a circle instead of placing them on the main base manually.

After finishing this first part, I duplicated the whole piece and stacked three layers of the shape. On the top layer, I created a new circular shape and smoothed the upper ends of the cylinders to make them look more like a rounded rocket tip.

I first drew a rectangle to create the bottom piece and extruded it. Then I used the line tool in Sketch to draw a combined triangle-and-rectangle shape, creating both the triangular and rectangular parts in one sketch, and extruded it. After finishing the first wall, I duplicated it using **Copy Here** and placed it on the opposite side. Then I created the simple side walls with sketches and completed the base structure by extruding them.

After the walls and the floor were done, it was time to make the roof. I used the triangular part of the complex walls to give the roof the classic birdhouse look, and then repeated the same process on the opposite side. Once the main structure was complete, I created the holes using the **Remove** option in Extrude. Lastly, I added a door stand block, which completed the birdhouse project.

I first created a cube using sketch and extrude. Then, to make the sides of the dice, we used the tool called 3D line to create a line that travels through the cube from the opposite corners. Then we hid all the other objects and planes and created planes on the opposite ends of the 3D line we just created. Then we reopened the other parts to create the actual indentations of the corners of the actual cube. Then we removed the circles that we had drawn on the plane that we just created for the indentation to happen. After one corner was done, we used the front plane to create the lines that would help us use the circular pattern. We went all the way around the cube but the bottom part and made them be convert entity then construct geometry. After we used the circular pattern, we chose the indented part and chose the center piece that we had just created to make it revolve around the center. After the first part of circular pattern was complete, we then created another plane right in the middle of the indented part of the cube using the mid plane. After, we used the mirror tool to copy the indented part to the other side of the cube. Then the main shape was complete — all we were left to do was to sketch and extrude our name wherever we liked.

I really found it hard to use the circular pattern since it needed the convert entity and construct geometry. Other than that, the 3D lines tool was new, so it was hard at first, but I handled it pretty well. Overall, it was a useful exercise.
